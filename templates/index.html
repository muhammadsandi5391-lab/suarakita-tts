SuaraKita

Ubah narasi menjadi audio MP3 dengan pilihan karakter suara.

Tipe suara menyesuaikan karakter yang dipilih.
Tidak ada batas karakter pada kolom ini. Batas pemrosesan server saat ini 100.000 karakter per proses.

Audio dibuat di server lalu dikirim sebagai file MP3. Di Android, file biasanya masuk ke folder Download/Penyimpanan internal melalui pengelola unduhan browser. Efek emosi menggunakan pengaturan kecepatan dan tinggi nada, jadi hasilnya dapat berbeda menurut suara.
